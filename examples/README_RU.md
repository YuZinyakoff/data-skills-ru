# Учебные Примеры

Все тексты составлены для документации. Примеры показывают поведение проверенной версии и не являются новой оценкой её точности.

| ID | Положительные группы | Пояснение |
|---|---|---|
| example-01 | D, AD | Явное требование инструмента работы с базами данных. |
| example-02 | E | Программирование без самостоятельной аналитической задачи. |
| example-03 | A, AD, E | Отдельные основания ИИ и общего ИТ. |
| example-04 | C, AD | Специализированное средство анализа и представления данных. |
| example-05 | B, AD | Прямо названный количественный метод. |
| example-06 | нет | Общих финансовых формулировок недостаточно для специальных компетенций AD. |
| example-07 | нет | Обычная офисная грамотность. |
| example-08 | нет | Только название специальности в дипломе. |
| example-09 | нет | Описание технологий компании без собственного требования к кандидату. |
| example-10 | нет | Обещание будущего обучения. |
| example-11 | E | Преподавание конкретной ИТ-дисциплины. |
| example-12 | D, AD, E | Пересечение технической работы с данными и ИТ-администрирования. |
| example-13 | C, D, AD | Общая аналитическая задача подтверждается специальным инструментом в другом поле. |
| example-14 | F | Вспомогательная промышленная группа, вне AD. |

Исходные короткие формулировки даны в [input.jsonl](input.jsonl), результат в [expected-flags.csv](expected-flags.csv). Для запуска выполните команду из основного [руководства](../README.md). Порядок строк CSV может отличаться; сопоставляйте их по `identifier`.
