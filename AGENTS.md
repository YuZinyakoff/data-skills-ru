# Работа с репозиторием

- Начни с README.md. Основной результат: фиксированный словарь и локальный классификатор, а не обучаемая модель.
- `_engine.py` и `data/lexicon.csv` идентифицируются хешами в `data_skills_ru/data/revision.json`.
- Изменения поведения делай отдельной явно запрошенной версией; не подменяй оценки качества старой версии новыми утверждениями.
- Проверки: `python -m unittest discover -s tests -v`.
- В примерах используй искусственные тексты. Корпуса, персональные данные, токены и индивидуальную исследовательскую разметку в репозиторий не добавляй.
- При изменении упаковки проверь установку собранного wheel вне исходного каталога.
- Лицензии разделены по видам материалов, см. LICENSE.md.
