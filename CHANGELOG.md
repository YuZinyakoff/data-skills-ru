# Изменения

## 0.1.0

Первая версия словаря и программы для самостоятельного использования.

- Словарь из 222 записей, поиск через RE2 и контекстная проверка упоминаний.
- Добавлены установка Python-пакета, API и командный интерфейс для JSONL, CSV и Parquet.
- Добавлены русское руководство, программные тесты, искусственные примеры и инструкция для агента.
- Включены агрегированные оценки качества и методические основания.
- Код лицензирован по MIT; словарь по CC BY 4.0.
- Обязательная зависимость: `google-re2`. Чтение Parquet устанавливается отдельно.

Дата публичного размещения фиксируется при публикации.
