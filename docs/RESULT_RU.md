# Паспорт программно-словарного результата

**Название:** Data Skills RU: словарь компетенций работы с данными и ИТ.

**Автор:** Юрий Зиняков.

**Версия:** 0.1.0.

## Краткое описание для отчёта

Разработан воспроизводимый русскоязычный словарно-контекстный инструмент
для измерения явно заявленного спроса работодателей на специальные
компетенции работы с данными и общие ИТ-компетенции по текстам вакансий.
Словарь включает 222 поисковые записи, объединённые в шесть групп.
Программная реализация учитывает варианты формулировок и контекст
упоминания, формирует бинарные показатели и сохраняет основания решений.
Подготовлен самостоятельный репозиторий с кодом, подробной русскоязычной
документацией, искусственными примерами, тестами и агрегатами проверки
качества. Код распространяется по MIT, словарь по CC BY 4.0.

## Состав результата

- Машиночитаемая таблица поисковых выражений, полей и условий.
- Исполняемый Python-пакет с API и командным интерфейсом.
- Обработка JSONL, CSV и Parquet с проверкой входов и сохранением контрольных сумм.
- Документация о содержании групп, происхождении понятий, контекстных правилах и качестве.
- Четырнадцать искусственных примеров с ожидаемыми ответами и программные тесты.
- Инструкция применения для исследовательского агента.
- Метаданные цитирования, лицензии и манифест версии.

## Проверенная область применения

Исторический корпус «Работы России» за 2018–2020 годы: 6 087 485
объявлений. Оценка по LLM-assisted разметке с авторским контролем:
для AD точность 93,7%, полнота 59,2%; для E 95,8% и 70,5%.
Интервалы и дизайн приведены в [описании качества](QUALITY_RU.md).
Перенос на другие корпуса требует самостоятельной проверки.

## Подтверждение версии

Файлы, размеры и контрольные суммы поставки перечислены в
`RELEASE.json`; сведения о словаре и классификаторе приведены в
`data_skills_ru/data/revision.json`. Команда
`python -m unittest discover -s tests -v` проверяет программную реализацию.
